¿Qué es HTML?

Introducción

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para crear y estructurar páginas web. Es el componente fundamental para la creación de sitios web, ya que define la estructura y el contenido de una página web.

¿Cómo funciona HTML?

HTML utiliza etiquetas (conocidas como "tags") para definir elementos dentro de una página web. Estas etiquetas son interpretadas por los navegadores para mostrar la información al usuario. A continuación, se mencionan algunos ejemplos comunes de etiquetas HTML:

  • <h1>: Encabezado principal de la página.
  • <p>: Párrafo de texto.
  • <a>: Enlace a otra página o recurso.
  • <img>: Imagen dentro de la página.
  • <ul> y <ol>: Listas desordenadas u ordenadas.

Elementos básicos de una página HTML

Una página HTML básica se compone de una estructura que incluye los siguientes elementos esenciales:

  • <html>: Contenedor principal de todo el contenido HTML.
  • <head>: Contiene información meta sobre la página, como el título o enlaces a hojas de estilo.
  • <body>: Contiene el contenido visible de la página, como texto, imágenes y enlaces.

Ejemplo básico de código HTML

            <!DOCTYPE html>
            <html lang="es">
                <head>
                    <meta charset="UTF-8">
                    <title>Mi Página Web</title>
                </head>
                <body>
                    <h1>Bienvenido a mi página</h1>
                    <p>Este es un párrafo de ejemplo para mostrar cómo se usa HTML.</p>
                </body>
            </html>
