¿Qué es CSS?

Introducción a CSS

CSS (Cascading Style Sheets) es un lenguaje de diseño que se utiliza para darle estilo a los documentos HTML. CSS permite controlar el aspecto visual de las páginas web, como los colores, las fuentes, los márgenes, el espaciado y la disposición de los elementos en la página.

¿Cómo funciona CSS?

CSS funciona mediante la asociación de reglas de estilo a los elementos HTML. Estas reglas definen cómo se deben mostrar los elementos en el navegador.

¿Qué contiene una regla CSS?

Una regla CSS consta de dos partes principales:

  • Selector: El elemento HTML al que se le aplicará el estilo (por ejemplo, un párrafo o un encabezado).
  • Declaración: La propiedad de estilo que se quiere aplicar y su valor (por ejemplo, color o tamaño de fuente).

Ejemplo de código CSS

            h1 {
                color: blue;
                font-size: 36px;
            }

En el ejemplo anterior, se está aplicando un color azul y un tamaño de fuente de 36 píxeles al elemento <h1>.

Tipos de CSS

  • CSS en línea: Se aplica directamente a los elementos HTML usando el atributo style.
  • CSS interno: Se coloca dentro de la etiqueta <style> en el archivo HTML.
  • CSS externo: Se coloca en un archivo separado (.css) que se enlaza al HTML.

Ejemplo de cómo incluir CSS en un documento HTML

Este es un ejemplo de cómo se puede enlazar un archivo CSS externo:

            <head>
                <link rel="stylesheet" href="styles.css">
            </head>
